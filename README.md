# Swan skateboarder
A game about the Swan where you have to ride a skateboard and collect coins.

- You can buy skins and locations for coins.
- Easy and hard modes.
- Saves your coins and purchases the next time you enter the game.

Written in Lua and [LÖVE](https://love2d.org/).
